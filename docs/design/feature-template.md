# 機能設計メモ

このファイルをコピーして使う。未確認の項目には、誰が何を確かめるかを書く。PR から参照するときは、仕様と確認結果までたどれる場所に置く。

## Discover — 利用者と練習場面

- 対象の利用者と練習場面
- 観察した事実と出典（日時、Issue、観察メモなど）
- まだ確かめていない仮説と、確かめる方法

## Define — 今回解く課題

- 利用者が達成したいことと、現在困っていること
- 今回扱う範囲と、後に回す範囲
- 成功条件（誰が、どの環境と操作で、何をできればよいか）

## Develop — 操作と画面の案

- 代表タスクと主要フロー
- 比較した案、ワイヤーフレームまたは試作品、採用理由
- 確認した参加者と条件、迷った点、修正したこと

| 状態・場面   | 開始条件・入力 | 画面表示・文言 | フォーカス・保存・復帰 |
| ------------ | -------------- | -------------- | ---------------------- |
| 初期表示     |                |                |                        |
| 主要操作     |                |                |                        |
| 関係する例外 |                |                |                        |

## Deliver — 実装仕様と確認結果

- 確定した画面・文言、狭い幅と広い幅の挙動
- 再利用するトークンと部品、追加・変更するものと理由
- 受け入れ条件、確認手順と結果（端末・入力方法を含む）
- 設計と実装の差分、見送った事項、公開後に確認すること
